# TodoList — Full-stack приложение

Клиент-серверное приложение для управления списком задач (TodoList) с CRUD-операциями и защитой API по ключу `x-api-key`.

Проект — монорепо:

- `todo-frontend/` — клиент на React + Vite.
- `todo-backend/` — сервер на Express.

## Стек

- **Frontend:** React 18, Vite.
- **Backend:** Node.js, Express, dotenv, cors.
- **Хранилище:** in-memory массив (учебный проект).

## Требования

- Node.js ≥ 18
